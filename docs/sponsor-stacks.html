Sponsor stacks

One project can be entered into several sponsor tracks on Devpost. A stack works when each sponsor's tool does real work in your demo. This page shows which sponsors go together and which ones fight.

Three rules

Rule 1

Start with the base layer

These fit on top of almost any project. Use two or three of them.

Rule 2

Pick one lane

Sponsors in the same lane combine easily. Pick a lane and use two or three of its sponsors.
